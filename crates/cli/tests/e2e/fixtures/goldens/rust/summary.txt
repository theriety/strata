             carries; moving it moves both. A table's leaf is whichever unit
             that suggestion acts on: usually the whole file, sometimes one
             symbol or one call.

             roughly how many import connections it honors; a bigger number
             is more valuable to honor

             of one project. When two candidates share one structure, decide
             between them by intent, never by raw score.

             symbols within one file; a suggestion that changes no placement
             says so instead of shipping a table. Prose under each table is
             its caption and carries the why.
 names     : file, folder and symbol names always appear in `backticks`
 future    : anything today's strata cannot yet emit keeps the literal label
             "future capability — not in current output" (none apply here) —
             the label marks capability, never whether the advice is real
